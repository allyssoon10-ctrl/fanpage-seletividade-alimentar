# Landing page - Seletividade Alimentar Infantil

Página estática em HTML, CSS e JavaScript (sem dependências externas). A fotografia da autora está incorporada no próprio HTML.

## Como visualizar
Abra `index.html` em um navegador.

## Como publicar no GitHub Pages
1. Faça upload de `index.html` para a pasta que será publicada pelo GitHub Pages (raiz do repositório ou `/docs`, conforme a configuração do projeto).
2. Em Settings > Pages, selecione a branch e a pasta corretas.
3. Salve e aguarde a publicação.

## Atenção se o repositório usa React/Vite
Este arquivo é uma landing page HTML independente. Não substitua o `index.html` de um projeto React/Vite sem adaptar a estrutura de entrada do Vite. Para integrar ao app existente, o conteúdo deve ser convertido para o componente React usado pelo projeto.
